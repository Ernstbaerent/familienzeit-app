# Figuren: drei Sätze zur Auswahl (Entwurf)

> **ERZEUGT** von `npm run figures:preview` aus `scripts/lib/figures/`. Nicht von Hand ändern. Hintergrund, Regeln und offene Entscheidungen: [`docs/design/FIGUREN.md`](../FIGUREN.md).

Drei Figurensätze mit deutlich anderer Anmutung, je ein größeres Kind, ein kleineres Kind, ein Erwachsener und ein Haustier. Jeder Satz in **zwei Fassungen aus demselben Rig**: ohne Gesichtszüge (wie bisher) und mit zwei Punkten als Augen (sonst nichts).
Karten sind 2:1 (Kartengröße 312 px breit gezeigt), daneben die Daumennägel 96 × 48 und 64 × 32. **Prüfung für ein Maskottchen:** Kannst du dir Name und Figur auf einem T-Shirt oder in einem 5-Sekunden-Clip vorstellen?

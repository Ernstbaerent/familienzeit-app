# Sprachen und rechts-nach-links (RTL)

## Texte

- Jeder sichtbare Text steht in `src/locales/de.json` und `src/locales/en.json`.
- Im Code: `const { t } = useTranslation();` und dann `t('home.greeting')`.
- Neuer Text: denselben Schlüssel in **beiden** Dateien anlegen.
  `npx tsc --noEmit` meldet Tippfehler im Schlüssel und fehlende englische Texte.

## Welche Sprache die App zeigt

- Die App geht die Sprachen aus den Handy-Einstellungen der Reihe nach durch
  und nimmt die erste, die sie kennt (z. B. Türkisch, dann Englisch → Englisch).
- Kennt sie keine davon, zeigt sie **Deutsch**.
- Die Sprache wird beim App-Start gelesen. Nach einem Sprachwechsel am Handy gilt sie ab dem nächsten Start.
- Einrichtung: `src/lib/i18n.ts`.

## Neue Sprache hinzufügen (später: ar, tr, uk, ro)

1. `src/locales/<code>.json` anlegen (gleiche Schlüssel wie `de.json`).
2. In `src/lib/i18n.ts` bei `resources` eintragen, z. B. `tr: { translation: tr satisfies typeof de }`.

## Rechts-nach-links (Arabisch)

Expo spiegelt das ganze Layout automatisch, wenn das Handy auf einer RTL-Sprache steht
(`supportsRTL` in `app.json`). Damit das klappt, gelten im Code diese Regeln:

| Statt                           | Nimm                                         |
| ------------------------------- | -------------------------------------------- |
| `marginLeft` / `marginRight`    | `marginStart` / `marginEnd`                  |
| `paddingLeft` / `paddingRight`  | `paddingStart` / `paddingEnd`                |
| `left` / `right`                | `start` / `end`                              |
| `textAlign: 'left'`             | `textAlign` weglassen (folgt der Sprache)    |
| `borderLeftWidth` usw.          | `borderStartWidth` / `borderEndWidth`        |

- `paddingHorizontal`, `marginVertical` usw. sind unproblematisch.
- `flexDirection: 'row'` dreht sich in RTL von selbst um.
- Icons mit Richtung (Pfeile „weiter“/„zurück“) mit `mirrorInRTL` aus `src/lib/rtl.ts` spiegeln.

**Hinweis:** Solange es noch keine arabische Übersetzung gibt, sieht ein Handy, das nur auf Arabisch
eingestellt ist, die deutschen Texte im gespiegelten Layout. Richtig testen können wir RTL,
sobald Arabisch dazukommt.

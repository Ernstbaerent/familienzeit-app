# Baukasten: Vorschau aller Bausteine

> **ERZEUGT** von `npm run kit:preview` aus `assets/bausteine/`. Nicht von Hand ändern. Regeln und Ablauf: [README.md](README.md).

Alle Bausteine in der Zeichnungs-Palette, so wie sie auf einer Karte aussehen (Format 2:1, 400 × 200 Einheiten). Die kleinen Bilder daneben zeigen sie in Daumennagelgröße (96 × 48 und 64 × 32): Dort muss man das Motiv an seinen großen Flächen erkennen.

## Beispielszenen

Szenen aus den Bausteinen, geprüft mit den Regeln (Layout, Plätze, Rand, Ecken, Überdeckung, bei Aktivitäten auch Sicherheit und Textabgleich). Sie zeigen, dass die Bausteine zusammenpassen; es sind keine endgültigen Titelbilder.
